# Danh mục đào tạo

Mode: Operate. Mở rộng shell Admin và danh sách tài khoản hiện có, giữ navy/blue, Segoe UI, focus và nút cảm ứng 44px. Không thay DESIGN.md của prototype.

Admin tìm/lọc/phân trang khoa, ngành, môn và sửa bằng form inline. Tabs chỉ dẫn đến chức năng đã triển khai. Khoa phụ trách chọn khi tạo; trạng thái hiển thị bằng chữ. Lỗi giữ ô nhập, xung đột chặn lưu và cho phép chủ động bỏ bản sửa/tải lại. Empty state hướng dẫn thêm hoặc đổi lọc; loading/error có retry. Không tạo số liệu minh họa hoặc dữ liệu HUCE giả. Desktop bảng, mobile mỗi hàng nhóm lại theo CSS Admin hiện có.

Kết thúc bằng kiểm tra API, browser, render desktop/tablet/mobile, review và cập nhật bằng chứng triển khai. Không đổi bộ nhận diện.
