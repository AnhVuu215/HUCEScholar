# Thiết kế HUCEScholar

- `wireframe/`: prototype tĩnh và đặc tả màn hình ngày 11/10/2026.
- `tools/`: script kiểm tra trình duyệt, kiểm tra file độc lập và đóng gói.
- `_qa/`: ảnh và kết quả kiểm tra nội bộ, được gitignore.

Đầu ra để xem và chia sẻ nằm trong `docs/deliverables/HUCEScholar_Wireframe_Prototype.html` và `HUCEScholar_Wireframe_Design_Package.zip`. Mở HTML trực tiếp trong Chrome/Edge; không cần server hoặc cài dependencies để xem.

Mã HTML/CSS/JavaScript ở đây chỉ trình bày thiết kế, không phải backend hay quyết định stack sản phẩm. Danh sách màn hình, trạng thái, use case và phần chưa mô phỏng đầy đủ nằm ở `wireframe/DESIGN_BRIEF.md`.
